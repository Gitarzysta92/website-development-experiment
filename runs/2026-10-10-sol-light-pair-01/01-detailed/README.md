# Detailed Artifactory experiment package

Package `AF-D1`, revision `1.1`, compiled on 9 October 2026. This is the detailed arm of the prompting experiment: the supplied website inputs plus an upfront specification, solution structure, 23 concrete component/page implementation units with all applicable concerns, checks, and entry prompt.

Start a fresh run with this entire folder as the working directory and submit [prompt.txt](prompt.txt). The executor builds into `website/`. Use a separate copy for each model run so generated code and evidence do not carry between runs. The prompt does not require the operator to submit the units individually.

The historical “stop at input gathering” instructions describe the earlier snapshot. The subsequent user request authorizes this compilation and preparation of the entry prompt. Submitting that entry prompt starts website implementation. Neither compilation nor running the prompt grants production publication, DNS, paid-service, or business-approval authority.

The compiled target is a complete, locally runnable bilingual website with a working local test enquiry receiver and an implemented external-delivery adapter. Live delivery, factual/human translation approval, and publication retain their explicit prerequisites. A successful local experiment must not be reported as a live launch.

No website has been implemented or tested while preparing this package. Package consistency checks are recorded separately from future website evidence.

Revision 1.1 replaces the original phase-oriented units. Each unit implements and verifies one concrete piece; combined journeys remain plan checkpoints. The [superseded package](revisions/AF-D1-1.0.zip) is archived and must not be executed.
