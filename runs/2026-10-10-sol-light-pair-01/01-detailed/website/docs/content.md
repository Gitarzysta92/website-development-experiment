# Content and navigation

`content-routes.json` is the local copy of the compiled route catalogue. `src/navigation/index.ts` owns route, ancestry, project sibling and contact-context helpers. Each page has private structured EN/PL draft records under `content/pages/en/` and `content/pages/pl/`. `src/content/pages.ts` validates them with Zod and registers public page views; it strips source revision, editorial status and other private preparation fields before rendering. `src/pages/[...path].astro` composes the views. Shared layout, header and footer live in `src/layouts/` and `src/partials/`.

The records originate in the supplied October 2026 project context. Copy deliberately qualifies research, design and simulation and avoids clinical, commercial, financial, team and partnership claims without supplied approval. English and Polish wording and the public email candidate still need human review. Private draft review states are in `content/evidence/reviews.json`. `src/content/review.ts` computes digest-based invalidation of factual, localized and media-caption approvals. `scripts/check-publication.mjs` checks all 17 paired records, review digests, rights status, HTTPS origin and a private live-activation record before a published build can begin. The real drafts fail that gate. An isolated synthetic fixture tests gate acceptance and rejection without approving the actual content.

Edit the relevant paired JSON records, keep the same page ID and section IDs, run `npm run check`, `npm run test`, `npm run build`, `npm run check:links`, then inspect both localized pages. Changes to English facts require renewed factual and language review; Polish wording changes require renewed Polish review; media changes require renewed rights/content review. A seed/import operation must not overwrite authored records or grant human approval. Add a route only through the compiled package's revision policy. CSS/HTML diagrams are explanatory concepts, not measured plots or interface screenshots. The supplied design screenshots remain private under `inputs/`.
