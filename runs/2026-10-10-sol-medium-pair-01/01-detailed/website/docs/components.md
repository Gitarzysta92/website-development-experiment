# Shared component contracts

- **Runtime (`IU-RUNTIME`)** — `astro.config.mjs`, exact package pins and lock, `scripts/serve.mjs`. `npm run build` validates and prerenders content while retaining a dynamic API. `npm start` serves only on loopback and adds security/cache headers to static responses. Stop and restart to clear fixture receipts. A failed published build runs the gate before modifying `dist/`.
- **Content and routes (`IU-CONTENT`)** — `src/content/index.ts`, `content/pages/{en,pl}/`, `src/navigation/index.ts` and the compiled route register. Add an identity to the authoritative compiled plan before adding implementation pages; do not invent unregistered paths. JSON records require paired locales and at least two substantive sections. `scripts/seed-content.mjs` only creates missing records. `content/evidence/review-ledger.json` and `content/assets/registry.json` stay private.
- **Frame (`IU-FRAME`)** — `src/layouts/Shell.astro`, `src/styles/global.css`, `src/components/ui/Concept.astro`. The chosen white/mist/ink/purple/teal tokens are CSS variables. Concept figures explain proposed workflows and are explicitly labeled; they are not evidence of real output. Validate any new control on mobile and keyboard, then recheck all consumers.
- **Header (`IU-HEADER`)** — `src/partials/Header.astro`. Links come from page identity. Mobile disclosure owns transient state; Escape closes and returns focus. EN/PL links preserve matching `section-N` anchors. Update route labels in the route register, then rerun language and menu tests.
- **Footer (`IU-FOOTER`)** — `src/partials/Footer.astro`. It exposes company/project navigation, Privacy and the candidate email address. The mailbox owner must verify that address before publication. No private recipient configuration appears here.
- **Project navigation (`IU-PROJECT-NAV`)** — `src/partials/ProjectNav.astro`. It derives overview and siblings from `parent` and `project` in the route register; a new project child should not hardcode a menu. On narrow screens it wraps into normal flow.
- **Recovery (`IU-RECOVERY`)** — `src/middleware.ts`, `src/pages/404.astro` and `docs/migration.md`. The known redirects preserve language context and fragments. Test actual statuses after any path change; do not redirect arbitrary unknown routes to Home.

Page authors own their pair of JSON records and the links listed in `related`. The shared template renders them, while the project/technical/company composition branches give their content an appropriate reading frame. Every page-specific instruction is in `docs/pages/`.
