# Themes and appearance preferences: rules

Apply these rules when the [themes and appearance preferences capability](../../capabilities/themes.md) is selected, alongside the relevant [baseline and technical rules](../README.md). The capability contract supplies its inputs, applicability and verification cases.

<a id="theme-01"></a>

- **THEME-01** — Apply a stored preference early enough to prevent avoidable wrong-theme flashes.

<a id="theme-02"></a>

- **THEME-02** — Follow live system changes only when system mode is selected.

<a id="theme-03"></a>

- **THEME-03** — Synchronise relevant preference changes across tabs; controls remain operable if storage fails.

<a id="theme-04"></a>

- **THEME-04** — Cover native controls, dialogs, validation, privacy settings, images and focus states in every supported theme.

<a id="theme-05"></a>

- **THEME-05** — Keep appearance preference separate from permission for optional tracking.
