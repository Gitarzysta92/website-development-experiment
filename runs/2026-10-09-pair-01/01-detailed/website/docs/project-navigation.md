# Project reading frame (IU-PROJECT-NAV)
ProjectFrame receives the public page view and body slot. Breadcrumbs follows ancestors; ProjectNavigation follows the project's exact registered children, keeping ArtiSense and AIFIELD distinct. A detail arrival always names the parent and company. Section links use stable IDs shared by translations. No previous/next wrap or invented gallery is present.
On narrow screens the local navigation is a disclosure, with Escape return and resize reconciliation; without JS it stays expanded. The contents list remains normal flow when height is at most 600px and disappears as redundant navigation on narrow layouts, where all headings remain reachable in reading order. Adding a child/section updates the registry/record, not unrelated templates. Verify both project trees and long PL labels after owner changes.
