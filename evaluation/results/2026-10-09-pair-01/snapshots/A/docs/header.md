# Header (IU-HEADER)
SiteHeader receives id, locale, optional equivalent-section IDs and translationAvailable. Links use the route API. Native details exposes the project menu to mouse, touch and keyboard; Escape returns to its summary. The mobile button controls the same navigation, closes on Escape and resets on resize. Collapse occurs at shared 72rem because long Polish navigation plus the company CTA does not fit at 48rem. The header is normal flow below 600px height. No-JS navigation stays expanded and usable. No preference is persisted.
The current locale/page belongs to the URL; menu state belongs to this header instance. Section switching preserves only corresponding allowlisted IDs. Add destinations through navigation identity and update one partial, then recheck long-label PL, 320px, short landscape, open-resize and no-JS states.
