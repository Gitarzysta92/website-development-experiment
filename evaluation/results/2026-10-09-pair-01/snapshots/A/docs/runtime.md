# Runtime (IU-RUNTIME)
Run commands in website/. Use Node 24.21.0 and npm 11.19.0. The run-local runtime is .runtime/bin; prepend it to PATH. npm ci installs the pinned lock. npm run dev starts loopback development; npm run build selects a successful candidate; npm start serves the built output at http://127.0.0.1:4321. PORT and SITE_ORIGIN must agree. Port+1 is a loopback-only adapter process. No external service is required.
The bootstrap applies host restrictions, actual response headers, a streamed 32 KiB request limit and private-path exclusions around the standalone Astro server. Static editorial HTML is generated at build time. The API is request-rendered. Source/config must never be served from the repository root. Scripts under scripts/ own reproducible checks; a missing target is an error, never a passing check.
A failed candidate leaves dist unchanged. To recover a successful prior artifact, stop the server, move dist aside and rename .dist-previous to dist. To recover source, restore a saved source archive into a clean directory, npm ci, build and compare content fingerprints before starting. Generated artifacts contain no approval authority.

The build records both profile and canonical origin. Start refuses a mismatched profile/origin, and preview refuses a listening-port/origin-port mismatch. A successful candidate undergoes a public-output boundary scan before selection. `scripts/verify-recovery.mjs` is the executable recovery exercise; logs live under artifacts/recovery. It temporarily changes an authored draft and restores exact bytes, then checks rendered HTML identity and previous-artifact startup. Stop other servers first.
