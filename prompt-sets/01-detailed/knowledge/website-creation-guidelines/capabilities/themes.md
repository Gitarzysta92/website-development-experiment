# Themes and appearance preferences

## Applicability

The website offers selectable or system-driven appearance preferences. Select this contract in the [project brief](../templates/project-brief.md); it does not require adding the feature to another project. Apply the [shared selection and recording conventions](README.md#using-a-capability).

Subjects: Visual design and layout; interaction and accessibility; data, privacy and security.

## Inputs

supported themes, system default policy, persistence scope and any scoped product/project palettes.

## Rules

[THEME-01](../rules/capabilities/themes.md#theme-01), [THEME-02](../rules/capabilities/themes.md#theme-02), [THEME-03](../rules/capabilities/themes.md#theme-03), [THEME-04](../rules/capabilities/themes.md#theme-04), [THEME-05](../rules/capabilities/themes.md#theme-05).

These links are the authoritative definitions. Also apply relevant baseline and technical rules from the [rule catalogue](../rules/README.md).

## Verification

first entry, reload, navigation, system change, another tab, cleared/blocked storage and rendered contrast in interaction states.

Record conditions, revision/environment, actual results and unresolved gaps in the [acceptance report](../templates/acceptance-report.md). Selecting the capability or implementing its interface does not establish a pass.
