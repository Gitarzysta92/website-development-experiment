# Multiple languages: rules

Apply these rules when the [multiple languages capability](../../capabilities/languages.md) is selected, alongside the relevant [baseline and technical rules](../README.md). The capability contract supplies its inputs, applicability and verification cases.

<a id="lang-01"></a>

- **LANG-01** — Language switches lead to the equivalent content where it exists; missing translations have an explicit fallback rather than a broken route.

<a id="lang-02"></a>

- **LANG-02** — Page language, interface labels, metadata, image alternatives and relevant formatting agree.

<a id="lang-03"></a>

- **LANG-03** — Indexable translations use coherent canonical/alternate/sitemap relationships.

<a id="lang-04"></a>

- **LANG-04** — Language preference and automatic redirection, if used, must preserve deliberate visitor choice and direct links.

<a id="lang-05"></a>

- **LANG-05** — Test longer translations and relevant character coverage in the actual typography and layout.

<a id="lang-06"></a>

- **LANG-06** — Define translation review and whether edits invalidate a shared or language-specific approval.
